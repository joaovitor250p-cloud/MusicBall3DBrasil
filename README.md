# Music Ball 3D Brasil

Aplicativo musical 3D para navegador móvel, hospedável pelo GitHub Pages.

## Abrir
Use o GitHub Pages do repositório. A página principal é `index.html` e carrega Three.js via CDN (requer internet).

## Recursos da versão web
- Cenário e câmera 3D com trilhos, bolinha e instrumentos geométricos.
- Efeitos visuais, som sintetizado nos impactos e detecção aproximada de energia/batidas.
- Seleção de arquivos de áudio do celular, playlist e troca automática de faixa.
- Modos Sincronizado, Infinito e Surpresa, com variações procedurais de movimento.
- Controles de volume, reprodução e câmera.

## Limitações conhecidas
- Ainda não testado em dispositivos Android reais neste ambiente.
- Os três modos não geram uma coreografia musical precisamente sincronizada; são variações visuais.
- Músicas selecionadas via navegador precisam ser selecionadas novamente após fechar a página.
- A versão Unity em `Assets/` é um projeto separado e não é o que o GitHub Pages executa.
- Não há músicas comerciais incluídas por questões de direitos autorais.

## Publicação
No GitHub: Settings → Pages → Deploy from a branch → main / (root). O site fica em `https://joaovitor250p-cloud.github.io/MusicBall3DBrasil/` quando a publicação terminar.
